# 《六点下班》画风与资产方案

> 更新：2026-09-15。记录现有风格与下一版规范。已接入、已有源图、待制作分开标注。
> 关联：[游戏设计](游戏设计文档.md) · [办公室扩建](办公室扩建与沉浸设计.md) · [早期归档](画风与资产方案-早期归档.md)。

## 1. 当前方向

2D 微俯平面办公室、可辨识的动物员工，叠加下班前的疲惫、监控和轻度异常感。保留角色可爱度，让环境承担压迫感。当前环境已有旧家具、污渍、暗色地面和恐怖装饰，不再沿用旧稿“全部白棚黑白”的描述。

大厅写实透视图定位为屏幕里的监控画面；游戏世界仍用浅俯视 2D 插画。不能把大厅透视家具直接切进平面地图。

## 2. 新资产视觉规范

| 项目 | 要求 |
|---|---|
| 视角 | 正面为主、顶部浅俯视；竖线平行，不用 45° 菱形等轴 |
| 材质 | 哑光、少量纸感/磨损，正常缩放下仍可识别 |
| 色彩 | 炭灰、旧白为基底；茶水暖褐、厕所冷绿、档案灰蓝，低饱和 |
| 重点 | 交互物用稳定轮廓/小灯/提示；角色、门、目标对比度高于杂物 |
| 光照 | 轻量明暗；投影和闪灯由引擎单独绘制，不烘焙巨大光晕 |
| 磨损 | 集中于把手、桌边、地脚、出纸口，保留正常办公的可信度 |
| 避免 | 3D 粘土、油亮摄影家具、连续全屏噪点、重复血迹、复杂假文字 |

先让人相信这里有人上班，再用少量异常制造不安。异常不应成为每平方米都有的装饰。

## 3. 角色现状

| 员工 | 围巾识别色 |
|---|---|
| 小马 | 青色 `#3EE0F2` |
| 兔子 | 黄色 `#F4C14A` |
| 牛 | 红色 `#E23B3B` |
| 鹈鹕 | 紫色 `#7B5CFF` |

老板为老虎。资源加载支持 idle/walk/run/work/sleep/toilet 序列及缺图回退；回退能显示不等于所有动作已完成。鳄鱼、猫头鹰和换装尚属规划。

## 4. 场景分层

1. 结构：地板、墙、门框、窗，定义轮廓。
2. 功能：工位、咖啡、厕所、打卡机、会议位置，有明确交互点。
3. 生活：打印机、纸箱、外套、外卖、回收桶、清洁用品、缺叶盆栽，解释空间用途。
4. 反馈：出纸、蒸汽、待机屏、门禁灯、空工位灯，绑定真实状态。
5. 异常：非关键屏幕的影子、异常公告、偶发坏灯，低频且不伪装成可交互目标。

大型阻挡物单独 PNG；小桌面摆件可做成一组。公告正文、门牌、时钟和动态数字由 Godot 字体覆盖，保证中文清楚且可修改。

## 7. AI 制作与接入

- 使用内置 imagegen；单物件单次生成，固定视角、调色和磨损程度。
- 要求透明 PNG、真实 alpha、无地面、无烘焙投影、无正文；禁止假棋盘透明。
- 源图保留在 concept；通过审图后再复制进 game，不覆盖已有素材。记录完整提示词、路径、用途与状态。
- 入库检查边缘、透明度、脚底锚点、正常显示尺寸和遮挡；建议打印机宽 120–160 世界单位，推车宽 90–120，接入时再同角色对比。
- 道具用底部中心锚点；碰撞覆盖落地占用，不把拖把把手全部算成实心墙。
- 装饰、碰撞、阻挡视线分别定义；低对比纸片不能挡路。
- AI 不负责碰撞、门、寻路和技能范围，整张概念图不等于可玩地图。
- 灯、文字、蒸汽和声音由引擎组合，不为每个状态重复生成大纹理。

## 8. 画面验收

1280×720 下员工/老板镜头各检查：角色不被装饰吞没、门洞清楚、提示无遮挡、缩小后仍识别道具；地板无明显接缝，家具无白边和假透明；装饰咖啡杯不被误认成额外恢复点。

规划提供降低闪烁、关闭抖动和降低噪点的选项；关键声音配视觉提示。不能以黑屏和连续惊吓代替场景设计。
