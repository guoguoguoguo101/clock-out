# clock-out

中文名《六点下班》。1 个老板对 4 个员工的 2D 非对称办公室对战。引擎是 Godot 4.7，服务端权威。

设计文档：[`docs/游戏设计文档.md`](docs/游戏设计文档.md)

## 最快：进测试房间

双击 `play.bat`，或：

```powershell
godot --path . -- --test
```

会进大厅后立刻开测试房（空位是 Bot），直接在办公室里走、坐下、摸鱼、倒咖啡。

编辑器 F5 也行：大厅里先点身份，再点 **测试房间 · 直接进办公室**。

## 大厅

- **测试房间**：本机开房并马上开局，用来测交互
- **创建房间**：开房后等人，选老板或员工，再点开始
- **加入房间**：连 Go 服务端（默认 `127.0.0.1:27111`），开房或输入房间码

## 通用服务端

权威在 Go 进程里，不跑 Godot `--server`。

```powershell
cd server
go run ./cmd/clockout-server
```

或双击 `server.bat`。客户端用「接入监控」连接后，**开设房间**或输入 4 位房间码加入。每人可开自己的房间，多桌互不影响。

可选 `--port=27111`。端口占用则非 0 退出。

## 操作

- 员工：WASD，E 坐下 / 续命 / 捞人，F 摸鱼，Shift 冲刺（冷却 8 秒）
- 老板：WASD，E 约谈（盯着复盘会加速，走开同事能捞人），Q 拉去开会，R KPI，Shift 冲刺
