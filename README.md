# clock-out

中文名《六点下班》。1 个老板对 4 个员工的 2D 非对称办公室对战。引擎是 Godot 4.7，服务端权威。

设计文档：[`docs/游戏设计文档.md`](docs/游戏设计文档.md)

## 最快：进测试房间

双击 `play.bat`，或：

```powershell
godot --path . -- --test
```

会进大厅后立刻开测试房（空位是 Bot），直接在办公室里走、坐下、摸鱼、倒咖啡。

编辑器 F5 也行：大厅里先点身份，再点 **测试房间 · 直接进办公室**。

## 大厅

- **测试房间**：本机开房并马上开局，用来测交互
- **创建房间**：开房后等人，选老板或员工，再点开始
- **加入房间**：连通用服务端（默认 `127.0.0.1:27111`）

## 通用服务端

```powershell
godot --headless --path . -- --server
```

或双击 `server.bat`。客户端再用「加入房间」。

## 操作

- 员工：WASD，E 坐下 / 咖啡 / 厕所 / 打卡，F 摸鱼
- 老板：WASD，E 抓包，Q 开会，R KPI，Shift 冲刺
