# 办公流程道具图集

所有状态图集均为透明底的 2 x 2 网格，按阅读顺序使用：左上、右上、左下、右下。

| 图集 | 格位 |
| --- | --- |
| `printer_states.png` | 待机、吐纸、红灯、卡纸 |
| `approval_board_states.png` | 普通、已审批、驳回、过载 |
| `cctv_states.png` | 待机、巡视、锁定、故障 |
| `turnstile_states.png` | 锁定、扫描、放行、拒绝 |
| `office_flow_icons.png` | 红色工单、红章、飞纸、蓝章、卡纸警告、监控锁定 |

图片内不包含可读文字；“需求变更”“已抄送全员”等事件文案必须由运行时 UI 叠加，避免素材与玩法文案绑定。
